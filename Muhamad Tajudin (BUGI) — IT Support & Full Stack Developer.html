Proyek Unggulan

Rekap Produktivitas Karyawan: dari VB.NET ke Web

Aplikasi bantu untuk merekap produktivitas karyawan. Berawal dari aplikasi desktop VB.NET yang berkomunikasi dengan perangkat DCP lewat port serial: karyawan cukup mengetik atau memindai NIK, lalu keluar/masuk tercatat otomatis. Aplikasi berjalan di system tray, dan datanya dimigrasikan ke dashboard web real-time (durasi berjalan tiap detik, kartu berwarna per bagian, snapshot CCTV saat karyawan keluar) lengkap dengan riwayat harian serta laporan per tanggal dan per NIK.

VB.NETRS-232 / DCPReactPHP APIMySQLCCTV HikvisionLaporan

Klik gambar untuk memperbesar. Nama, NIK, wajah, dan data koneksi pada tangkapan layar sengaja disamarkan.
